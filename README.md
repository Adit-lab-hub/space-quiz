# Orbit Academy - Space Quiz

A self-contained, accessible space trivia quiz. Each run shuffles the ten questions, explains answer feedback, reviews missed answers at the end, and saves a personal best in browser storage when available. The quiz uses no dependencies, server, or build tools.

## Run locally

Open `index.html` in a modern web browser. No installation or build step is required.

## Deploy

GitHub Actions publishes `index.html` to GitHub Pages whenever changes are pushed to `main`. You can also start the **Deploy to GitHub Pages** workflow manually from the Actions tab.
